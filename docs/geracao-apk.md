# Gerando o apk

O APK será gerado com o **EAS Build**, sendo necessário instalar essa CLI e configurá-la para realizar a build do projeto. A configuração inicial da build será feita executando o seguinte comando no terminal após instalar a CLI:

```bash
eas build:configure
```

Após executar esse comando, será criado um arquivo `eas.json`, no qual serão passados os parâmetros necessários para realizar a build para Android.

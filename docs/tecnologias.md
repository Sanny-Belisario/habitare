# Tecnologias, bibliotecas e linguagens

A linguagem que será utilizada é o **typescript**, com ele, será utilizado a biblioteca **React Nativa** com **Expo**, para o desenvolvimento android.

Para o gerenciamento do banco, será utilizado a biblioteca **Drizzle-ORM**, um ORM de banco de dados, que tem como objetivo facilitar as querys

## Link das tecnologias
- [React Native](https://reactnative.dev/docs/environment-setup)
- [Expo](https://docs.expo.dev/)
- [TypeScript](https://www.typescriptlang.org/docs/)
- [Drizzle-ORM](https://orm.drizzle.team/docs/get-started)
